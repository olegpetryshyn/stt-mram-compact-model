# STT-MRAM Compact Model

This repository provides a compact Verilog-A model of a perpendicular-anisotropy CoFeB/MgO spin-transfer torque magnetic random-access memory (STT-MRAM) device. It combines Landau-Lifshitz-Gilbert-Slonczewski magnetization dynamics, bias-dependent tunnel magnetoresistance, and thermal switching effects for circuit-level simulation with OpenVAF and ngspice.
